# 수입식품 수입신고 구비서류 조회 플러그인

수입 국가, 생산지역, 품목, 식품 유형, 원재료를 받아 수입식품 수입신고 때 식약처(지방식품의약품안전청)에 제출하는 구비서류와 근거를 돌려준다. 농·임산물, 축산물, 수산물, 가공식품, 건강기능식품, 식품첨가물, 기구·용기·포장을 다룬다. 서류의 필수 여부는 공식 자료에서 만든 승인된 규칙으로 판정한다. 근거가 없으면 `UNKNOWN` 으로 답한다.

같은 판정 로직을 CLI, MCP 서버, Agent Skill, Python 함수로 쓸 수 있다.

기준일 2026-11-10. 버전 0.3.0, 규칙 v6(89개). 규칙은 공식 사이트 수집본에서 원문 인용 위치를 확인한 단계(`source_quoted`)이며 실무자 검토 전이다.

0.3.0 에서 이름을 `seafood-import-plugin` 에서 `food-import-plugin` 으로 바꾸고 범위를 수산물에서 수입식품 전체로 넓혔다. 버전별 변경은 [docs/spec.md](docs/spec.md) 3절과 4절에 있다.

## 빠른 시작

```bash
uv venv --python 3.12 .venv && uv pip install -e ".[dev]"
scripts/food-import docs "일본 홋카이도산 냉동 가리비 수입신고 서류 알려줘."
```

자세한 설치와 MCP·Skill 연결은 [docs/installation.md](docs/installation.md) 에 있다.

## 조회 예제

```bash
scripts/food-import docs "일본 후쿠시마산 쌀 수입 가능한가?"
scripts/food-import docs --origin 미국 --product 소고기 --state 냉동
scripts/food-import docs --origin 베트남 --product 과자 --ingredient 돼지고기
scripts/food-import docs --origin 태국 --product 망고스틴 --category 농산물      # 품목 사전에 없는 품목
scripts/food-import --json docs --origin 노르웨이 --product 연어 --state 냉동 --date 2026-12-01
scripts/food-import hygiene 페루
scripts/food-import search "젤라틴 증명서"
```

현재 규칙으로 나오는 결과 요약:

| 질문 | 수입 가능 여부 | 주요 서류 |
|---|---|---|
| 일본 홋카이도산 냉동 가리비 | 해당 금지 규칙 없음 | 필수: 방사능 검사증명서, 생산지증명서 |
| 일본 후쿠시마산 수산물 | 수입금지 | 서류 목록을 싣지 않고 금지 근거를 먼저 표시 |
| 일본 후쿠시마산 쌀, 나가노산 표고버섯 | 수입금지 | 현별 수입금지 품목(15개현)에 해당 |
| 일본 니가타산 쌀 | 해당 금지 규칙 없음 | 필수: 방사능 검사성적서를 포함한 일본 정부 증명서 |
| 일본산 소고기 | 수입금지 | 일본산 육류 및 원유 수입금지 |
| 일본 홋카이도산 치즈 | 판정 불가 | 필수: 생산지증명서, 수출 위생증명서 |
| 미국산 냉동 소고기 | 판정 불가(수입위생요건 고시 국가인지 확인 필요) | 필수: 수출 위생증명서 |
| 노르웨이산 냉동 연어 | 해당 금지 규칙 없음 | 필수: 수산물 위생증명서 |
| 중국산 다진마늘 | 해당 금지 규칙 없음 | 필수: 중국 정부 위생증명서 등 4종 |
| 뉴질랜드산 꿀 | 해당 금지 규칙 없음 | 필수: 뉴질랜드 정부증명서 |
| 베트남산 과자(원재료 돼지고기) | 해당 금지 규칙 없음 | 필수: 열처리 증명서·ASF 검사성적서·ASF FREE 증명서 중 하나 |
| 베트남산 과자(원재료 미입력) | 해당 금지 규칙 없음 | 조건부: 원재료에 걸린 서류(ASF, BSE, 젤라틴, 대마씨 등) |
| 인도산 향신료 | 해당 금지 규칙 없음 | 조건부: 검사명령 이행 성적서(금속성이물) |
| 중국산 PET 도시락 | 해당 금지 규칙 없음 | 조건부: 제조회사 재질 확인증명서 |
| 태국산 망고스틴(유형 미입력) | 해당 금지 규칙 없음 | 기본 서류만. 식품 유형을 되묻는다 |

모든 조회에 수입신고서와 한글표시 서류(시행규칙 제27조제1항)가 필수로, 제27조제1항제1의2~6호와 식약처 고시 제22·23조 서류가 조건부로 붙는다. 서류마다 근거 조문, 출처 주소, 원문 위치, 인용문이 따라온다.

입력값:

| 값 | 설명 |
|---|---|
| 원산지, 수출국 | 국가 사전은 수입식품정보마루의 국가 코드 목록(249개국)이다 |
| 생산지역 | 일본산이면 도도부현. 수산물, 농산물, 축산물, 가공식품 모두 지역으로 갈린다 |
| 품목 | 품목 사전에 있으면 식품 유형을 스스로 정한다 |
| 식품 유형 `category` | 농산물, 축산물, 수산물, 가공식품, 건강기능식품, 식품첨가물, 기구용기포장. 사전에 없는 품목일 때 준다 |
| 원재료 `ingredients` | 돼지, 반추동물(소·사슴·양), 젤라틴, 콜라겐, 우지, 대마씨 등. 주지 않으면 원재료에 걸린 서류를 조건부로 답한다. 해당 원재료가 없으면 빈 목록(`--ingredient 없음`)을 준다 |
| 상태, 가공 여부, 신고 예정일, 선적일 | 이전과 같다 |

서류가 아닌 내용은 따로 나온다.

- `prechecks`(신고 전 확인사항): 해외제조업소 등록(법 제5조), 축산물의 해외작업장 등록(법 제12조)과 수입위생요건 고시 국가(법 제11조), 동물성 식품의 정의(법 제2조), 위생약정국 수산물의 포장 표시(식약처 고시 제17조제5항)
- `advisories`(검사강화 게시물): 식품안전나라 검사지시 게시판에서 조회한 품목·식품 유형과 관련된 게시물과 본문
- `import_bans`(수입금지제품 게시물): 조회한 국가 이름이 제목에 든 게시물 제목
- `reference_notices`(관련 식약처 공지): 규칙에 반영하지 않은 위생증명서 서식 변경·전자증명서 공지 본문

뒤의 세 가지는 승인 절차를 거치지 않는 참고 정보다.

조회할 때 마지막 공식 출처 확인이 24시간보다 오래됐으면 먼저 확인한다(`--refresh` 로 항상, `--no-refresh` 로 생략). 확인에는 3분쯤 걸린다(요청 89건). 변경이 감지돼도 판정은 승인된 규칙으로 한다.

출력 형식은 Markdown(기본)과 JSON(`--json`)이다. JSON 의 주요 필드는 `importability`, `documents[].status`, `prechecks`, `advisories`, `import_bans`, `reference_notices`, `freshness_check`, `missing_info`, `assumptions`, `needs_confirmation`, `conflicts`, `data_basis`, `warnings` 다.

## 자동 업데이트

```bash
scripts/update_data            # 공식 출처 확인 → 변경이 있으면 검토 대기 등록 (종료 코드 0 변경 없음 / 3 변경 감지 / 2 실패)
scripts/food-import show-pending <ID>
scripts/food-import approve <ID> --by "<이름>" --verification expert_reviewed
```

변경은 감지만 하고 자동으로 적용하지 않는다. 승인 전까지는 기존 규칙으로 판정하고 결과에 미적용 변경 경고를 붙인다. 수집이나 파싱이 실패해도 승인된 규칙은 그대로다. 스케줄러·CI 연결, 수동 반영, 되돌리기는 [docs/operations.md](docs/operations.md) 에 있다.

## 출처와 이용 조건

2026-11-10 에 각 사이트의 저작권 안내를 확인한 내용이다. 이 저장소의 코드가 아니라 `data/raw/`, `data/normalized/`, `data/rules/`, `tests/fixtures/http/` 에 든 공공기관 자료에 해당한다.

| 자료 | 출처 | 이용 조건 확인 결과 |
|---|---|---|
| 법령(수입식품안전관리 특별법, 같은 법 시행규칙), 고시(약정 고시 13건, 「수입식품등 신고 및 검사에 관한 규정」과 별표 2) | 법제처 국가법령정보센터 `www.law.go.kr` | 법령과 고시는 저작권법 제7조에 따라 보호받지 않는 저작물이다 |
| 구비서류 목록 공지와 엑셀, 검사명령 현황, 위생약정·위생증명서 공지, 수입금지제품 게시물 제목, 국가 코드 목록 | 식품의약품안전처 수입식품정보마루 `impfood.mfds.go.kr` | 아래 식약처 저작권정책 적용. 수집한 페이지에 공공누리 표시가 없다 |
| 일본산 식품 수입제한조치 | 식품의약품안전처 수입식품방사능안전정보 `radsafe.mfds.go.kr` | 위와 같다 |
| 검사지시 게시물 제목과 본문 | 식품의약품안전처 식품안전나라 `www.foodsafetykorea.go.kr` | 위와 같다 |

식약처 저작권정책(`https://www.mfds.go.kr/wpge/m_34/de010803l001.do`)에 실린 저작권법 조문은 다음과 같다.

- 제24조의2(공공저작물의 자유이용): 국가가 업무상 작성해 공표한 저작물은 허락 없이 이용할 수 있다. 예외는 국가안전보장 정보, 개인의 사생활 또는 사업상 비밀, 다른 법률로 공개가 제한된 정보, 한국저작권위원회에 등록돼 국유재산으로 관리되는 저작물이다.
- 제37조(출처의 명시): 위에 따라 이용할 때는 출처를 명시한다.
- 제36조: 번역·개작해 이용할 수 있다.

이 저장소의 식약처 자료는 식약처가 업무상 작성해 누리집에 공표한 것이고 위 예외에 해당하지 않는다고 보아, 제24조의2에 따라 출처를 밝히고 싣는다. 이것은 조문에 따른 해석이며 법률 자문을 받은 것은 아니다.

같은 정책 페이지는 공공누리가 부착되지 않은 자료는 게시물 등록 부서 담당자와 사전에 협의한 뒤 이용해 달라고 안내한다. 수집한 페이지에는 공공누리 표시가 없고 담당 부서와 협의하지는 않았다. 게시물에 제3자가 권리를 가진 자료가 들어 있으면 자유이용 대상이 아니다. 게시물의 첨부 서식 파일(외국 정부 증명서 서식 등)은 받지 않았다.

출처 표시: 이 저장소의 식약처 자료는 식품의약품안전처가 수입식품정보마루, 수입식품방사능안전정보, 식품안전나라에 게시한 것이다. 자료별 게시일, 주소, 수집 시각은 `data/raw/index.jsonl` 과 각 규칙의 `source` 에 있다. 원문을 수정하지 않았고, 규칙의 `condition_note` 만 이 프로젝트가 요약해 쓴 것이다. 식약처는 이 프로젝트와 관계가 없으며 판정 결과를 보증하지 않는다.

## 구현되지 않았거나 공식 검증이 필요한 항목

판정 결과에 영향을 주는 순서로 적는다.

1. **실무자 검토 전이다.** 규칙 v6 은 원문 인용 위치만 확인했다. 실무자가 `scripts/food-import rules` 로 89개 규칙을 원문과 대조한 뒤 `review` 명령으로 검토 완료를 기록해야 한다. v2~v6 은 이 프로젝트를 만든 에이전트가 "자동 구축, 실무자 검토 전"으로 승인했다. 되돌리려면 `scripts/food-import rollback <버전> --by "<이름>"` 을 쓴다.
2. **축산물의 수입 가능 여부는 판정하지 않는다.** 축산물은 수입위생요건이 고시된 국가·지역에서만 수입할 수 있다(법 제11조제3항). 그 고시의 이름과 목록 위치를 확인하지 못했다. 그래서 축산물은 `UNKNOWN` 으로 답하고 조문만 알린다. 해외작업장이 등록돼 있는지도 조회하지 않는다. 가축전염병 예방법에 따른 검역(농림축산검역본부)은 범위 밖이다.
3. **동물성 식품 여부는 판정하지 않는다.** 육류·유·알을 원료로 쓴 가공식품이 법 제2조제1호의2의 동물성 식품인지는 대통령령에 달려 있다. 수출 위생증명서를 조건부로 답하고 정의 조문을 함께 보여 준다.
4. **BSE 관련 36개국 목록이 없다.** 구비서류 목록이 국가를 열거하지 않는다. 연번 2·7(반추동물 원료, 우지, 젤라틴·콜라겐, 제2인산칼슘)은 국가를 판정하지 못하고 조건부로만 답한다.
5. **ASF 발생국 73개국 중 1개국을 읽지 못했다.** 각주의 "리트비아"가 국가 사전에 없다(라트비아의 오기로 보이지만 고쳐 읽지 않았다). 규칙에서 빠졌고 경고로 표시된다.
6. **원재료 판정은 입력에 달려 있다.** 원재료를 주지 않으면 원재료에 걸린 서류가 모두 조건부로 나온다. 원재료 사전은 12개 묶음이다. 연번 14의 제외 원재료(돼지 젤라틴, 라드, 합성향료)는 판정하지 않고 원문만 보여 준다.
7. **일본산 농산물 금지 품목은 낱말 대조다.** 원문의 "버섯류", "엽채류" 같은 분류와 조회한 품목명을 글자로 대조한다. 사전에 없는 품목이 그 분류에 드는지는 알 수 없다.
8. **위생증명서를 `필수`로 올린 판단의 근거.** 수산물 약정국 12개국의 원물 수산물에 위생증명서를 `REQUIRED` 로 답한다. 근거는 시행규칙 제27조제1항제7호와 각 약정 고시의 증명서 조문이다. 품목이 고시 적용대상에 드는지, 등록시설 제품인지는 판정하지 않는다.
9. **수산물 약정국 목록은 한정 열거가 아니다.** 고시명을 등록한 13개 고시만 받는다. 12개국 밖의 국가는 `UNKNOWN` 이다.
10. **활수산물과 가공 수산물의 위생증명서**는 고시 적용대상 조문을 인용하고 `UNKNOWN` 으로 답한다(러시아 수산가공품은 `CONDITIONAL`).
11. **일본 "생산지역"의 기준**(어획 해역, 양륙지, 재배지, 제조지)을 공식 자료에서 확인하지 못했다. 식약처 페이지의 도도부현 구분을 그대로 적용한다. 일본산 원료를 쓴 가공식품은 제조·생산 지역 기준으로만 판정한다.
12. **개별 제품·업체 단위 수입금지와 수입중단**은 규칙에 없다. 수입금지제품 게시물 제목만 참고로 붙인다.
13. **사진 제출 제외 대상 공지**(제27조제1항제1호의2 나목)를 찾지 못했다. 별표 9 제2호가목1)~3)은 원문을 붙였다.
14. **유전자변형식품, 유기식품, 건강기능식품의 개별 인정 서류**처럼 구비서류 목록과 제27조 밖에 있는 요건은 수록하지 않았다. 제27조제1항제3호(유전자변형식품)는 조문 원문만 조건부로 보여 준다.
15. **검사강화 게시물과 관련 공지는 참고 정보다.** 본문에서 대상 품목·기간을 뽑아 판정하지 않는다.
16. **식약처 외 기관 요건**(관세청 통관, 식물검역, 동물검역, 수산생물 검역, 어획증명 등)은 판정하지 않는다.
17. **Open API 는 쓰지 않았다.** 법령과 고시는 국가법령정보센터 공개 웹페이지에서 받는다. HS 코드 연결도 없다.
18. **조건 문구.** 제27조제1항 각 호는 조문 원문을 조건으로 쓴다. 그 밖의 규칙은 이 프로젝트가 쓴 요약을 "조건(요약)"으로 표시하고 원문을 함께 싣는다.
19. **품목 사전은 100여 개 묶음**이다. 사전에 없는 품목은 식품 유형을 함께 받아 유형 단위 규칙만 판정한다. 학명 사전은 없다.
20. **HWP 첨부 파서가 없다.** PDF 는 글자를 뽑을 수 있는 것만 읽는다.
21. **자연어 해석은 사전 대조 방식**이다. 복잡한 문장은 에이전트가 해석해 구조화된 값으로 넘기는 것을 전제로 한다.
22. **과거 시점 규정은 없다.** 기준일이 수록된 규정의 시행일 이전이면 판정하지 않고 그 사실을 적는다.

명세와 원 요청서 대비 변경 사항은 [docs/spec.md](docs/spec.md) 에 있다.
